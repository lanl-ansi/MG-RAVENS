# Hand Template Alignment Log

This file tracks intentional hand-template edits that align `ravens/lib/template.json` with the current valid simplified UML diagrams and the supported auto-template output.

| Entry | What was changed | Why it was changed |
| --- | --- | --- |
| `CommunityFacility` | Collapsed the hand-only `GridFacility` and `NonGridFacility` wrapper into the same plain `CommunityFacility` object shape used by the auto template. | `CommunityFacility` only has the richer split on `Root` plus excluded `Inf*` diagrams, so the hand wrapper was broader than the current valid simplified-diagram scope. |
| `Message` | Replaced the hand-only array of `Error`/`Warning`/`Info`/`Debug` variants with a plain `Message` object. | Those message variants only show up through the hand/root view, not the current valid simplified diagrams, so the simpler object shape is the supported one today. |
| `LoadGroup.EnergyConsumers` | Removed subtype-only `ConformLoadGroup.EnergyConsumers` and `NonConformLoadGroup.EnergyConsumers`, and moved the supported subtype choices onto the shared `LoadGroup.EnergyConsumers` reference list. | The valid diagrams support the shared `LoadGroup` relationship, but not separate labeled `ConformLoadGroup` or `NonConformLoadGroup` energy-consumer associations. |
| `ActivityRecord.EnvironmentalEvent` | Changed `EnvironmentalEvent` from an array of detailed objects to the single embedded object shape used by the auto template, and dropped the extra nested `EnvironmentalPhenomenon` detail. | The hand array shape was relying on a relationship that is not visible as a valid labeled simplified-diagram association. |
| `EnergyAreaConnector` | Removed the `EnergyAreaConnector` branch and its `EnergyAreaConnector.EnergyAreas` pointer array from the hand template. | `EnergyAreaConnector` only appears on `InfFacilities`, so that branch is outside the current valid simplified-diagram set. |
| `GeographicalRegion` targets | Narrowed `ProposedSiteLocation.Region`, `EconomicProperty.Regions`, `LocationalMarginalPrices.Regions`, `CapacityPrices.Regions`, and `CoincidentPeakPrices.Regions` to `SubGeographicalRegion`, and removed the unsupported reverse `SubGeographicalRegion.Region` pointer. | The valid kept diagrams consistently point these relationships at `SubGeographicalRegion`, not a `GeographicalRegion | SubGeographicalRegion` union or a reverse `SubGeographicalRegion.Region` reference. |
| `PredictedEmissions` | Collapsed `PredictedEmissions` to an empty object, removing the hand-only `Location | ProposedSiteLocation` location union and extra algorithm-property reference. | `PredictedEmissions` only appears on `Root`, so the richer hand structure is outside the supported simplified-diagram scope. |
| `ProposedBatteryUnitOption.InverterController` | Removed the unsupported `InverterController` polymorphic object from `ProposedBatteryUnitOption`. | `ProposedBatteryUnitOption` appears on valid diagrams without that association, and the control-mode variants live outside `SimplifiedDiagrams`. |
| `ArTapStep.TapChanger` | Replaced the `RatioTapChanger | PhaseTapChanger` reference union with the base `TapChanger` reference used by the auto template. | The valid diagrams support `TapChanger` on `ArTapStep`, but not the hand-only subtype union because `RatioTapChanger` and `PhaseTapChanger` are outside the current valid diagram set. |
